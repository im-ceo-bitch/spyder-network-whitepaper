# Как бесплатно опубликовать Spyder Network на GitHub

Этот ZIP содержит **структуру публичного исследовательского репозитория**, а не готовую сеть. Рекомендуемое название репозитория: `spyder-network-whitepaper`.

## Вариант A — распаковщик уже установлен

1. Убедись, что в репозитории есть `.github/workflows/auto-unpack.yml` из отдельного пакета **SPYDER_GITHUB_AUTO_UNPACK_BOT.zip**.
2. Убедись, что у GitHub Actions есть permission `contents: write`, а default branch разрешает запись боту.
3. В GitHub нажми **Add file → Upload files**, загрузи **в корень репозитория** файл `SPYDER_NETWORK_REPOSITORY_v0.2.0.zip` и нажми Commit changes.
4. Открой Actions → Auto Unpack ZIP Updates и убедись в успешном выполнении.
5. Проверь, что появились `README.md`, `README_RU.md`, `docs/whitepaper/`, `docs/tokenomics/`, `docs/roadmap/` и остальные файлы. Загруженный ZIP должен исчезнуть из текущей ветки после коммита бота.

## Вариант B — распаковщика нет

GitHub **не распаковывает ZIP автоматически**. Сначала вручную создай файл `.github/workflows/auto-unpack.yml` из отдельного ранее подготовленного пакета распаковщика (Create new file → Commit changes), затем выполняй вариант A. Сам этот ZIP **не устанавливает workflow**, потому что для его запуска workflow уже должен существовать в репозитории.

Либо распакуй этот архив на компьютере и загрузи папки и файлы напрямую через интерфейс GitHub, если не хочешь пользоваться Actions.

## Обязательная проверка перед публичной публикацией

- Проверь, что в документах нет персональных данных и секретов.
- Убедись, что названия и статус проекта совпадают с реальностью, а предварительные экономические параметры не представлены как утверждённые.
- Открой `README.md` и обе PDF-версии, проверь, что ссылки работают.
- Учти, что GitHub удаляет ZIP только **из текущего состояния репозитория**: файл остаётся доступен в истории Git. Не загружай секреты, даже если бот потом удаляет архив.

## GitHub Release

После появления всех файлов: GitHub → Releases → Draft a new release → тег `whitepaper-v0.2.0`. Название релиза: `Spyder Network — Research Whitepaper v0.2.0`. В описании используй текст из [`RELEASE_NOTES_v0.2.0.md`](RELEASE_NOTES_v0.2.0.md).

Проверь хеши через [`SHA256SUMS.txt`](SHA256SUMS.txt). Не называй результат «зарегистрированным товарным знаком», «запущенным mainnet» или «официальным токеном в обращении». GitHub timestamp фиксирует публичную версию документа, но не даёт исключительных прав на название.

Опционально позже: архивирование конкретного релиза через https://zenodo.org для получения DOI.
