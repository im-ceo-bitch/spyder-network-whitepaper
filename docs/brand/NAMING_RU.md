# Наименования Spyder Network

Единое написание бренда — **SPYDER**, через букву **Y**. Не использовать в официальных заголовках `Spider Blockchain` или `SpiderCoin`: это орфографические варианты, от которых отказались.

| Наименование | Роль |
|---|---|
| **Spyder Network** | Общий публичный бренд и название экосистемы |
| **SpyderChain** | Предлагаемая независимая блокчейн-сеть Layer 1 |
| **SpyderCoin (SPD)** | Предполагаемый нативный актив; тикер SPD — предварительный |
| **Spyder Wallet** | Приложение криптовалютного кошелька |
| Spyder Messenger, Spyder ID, Spyder Terminal | Дополнительные концепции экосистемы; не заявлены готовыми продуктами |

Права на товарные знаки не приобретены и не проверены для всех рынков. **Публичное размещение названия не резервирует его.** Приоритет текущего этапа — документирование истории проекта без расходов на регистрацию. Перед рыночным использованием необходим поиск совпадений и проверка местных правил.

Названия репозиториев, идентификаторы сети, публичные адреса и формат адресов **не изменять автоматически** только ради брендинга: совместимость требует отдельной технической миграции.
