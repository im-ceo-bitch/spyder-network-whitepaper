# Spyder Network — Research Whitepaper v0.2.0

**Research draft prepared on 22 November 2026. Actual public release date is defined by GitHub.**

This release publishes an independent research proposal for **Spyder Network**, **SpyderChain**, **SpyderCoin (SPD)** and **Spyder Wallet**. It contains a full Russian research Whitepaper, a shorter English summary and an editable, formula-based M-01 monetary model.

All token supply, allocation, fee-policy, validator and staking parameters are **unapproved candidates**. The publication does not represent a working or audited mainnet, actual token issuance, investment opportunity, token sale, guaranteed price appreciation, registered trademark or formal entity incorporation.
