# Security and authenticity

**Status:** Research draft. This repository is **not** an audit report, blockchain node, mainnet launch or token contract deployment.

* Never publish seed phrases, wallet private keys, signing certificates, access tokens, secrets or personal identity documents in Git or GitHub Releases.
* No SPYDER NETWORK sale, token distribution, exchange listing, staking APY or return on investment is authorized by the appearance of this repository.
* Do not send funds to addresses promoted by third parties as SpyderCoin (SPD) until trustworthy and verified, official project announcements and corresponding technical proofs exist.
* Do not treat test tokens as valuable assets.
* Vulnerability reports should not include exploit details, credentials or user data in public issues. The maintainer should publish an independent secure reporting method before accepting production security reports.
* Token supply, chain addresses, consensus and validator claims must be linked to independently reproducible source code before they are advertised as implemented.
