# SPYDER NETWORK — публичный исследовательский репозиторий

**Spyder Network** — название экосистемы. **SpyderChain** — проект собственной сети Layer 1. **SpyderCoin (SPD)** — предполагаемая нативная монета. **Spyder Wallet** — кошелёк экосистемы.

**Статус: Whitepaper v0.2.0, исследовательская редакция от 22.11.2026.** Публикация не означает наличия mainnet, выпущенных токенов, листинга или зарегистрированных товарных знаков. Вся экономическая модель **M-01 предварительная**.
