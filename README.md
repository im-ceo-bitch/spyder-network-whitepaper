# SPYDER NETWORK

**Spyder Network · SpyderChain · SpyderCoin (SPD) · Spyder Wallet**

> **Public research draft — v0.2.0.** This repository documents an independent blockchain-ecosystem proposal and an *unapproved* token-economic model. It is **not** evidence of an operational mainnet, audited consensus, publicly issued coin, token sale, investment opportunity, or trademark registration.

Spyder Network is the proposed ecosystem. **SpyderChain** is a proposed independent Layer-1 blockchain; **SpyderCoin (SPD)** is its proposed native asset; **Spyder Wallet** is the proposed user-facing wallet. The long-term objective is a safe, usable digital-asset ecosystem with transparent economic rules—not a guaranteed token price.

## Monetary-policy candidate, **NOT implemented**

* Maximum theoretical supply under study: **9,999,999,999 SPD**.
* Research proposal M-01: up to **75% at genesis**, largely locked; **25%** reserved for declining validator rewards over **15 years**.
* Research proposal for network fees: **90%** to validators and **10%** to protocol treasury; **0%** burn initially.
* These numbers are **not final protocol specifications**, issued token quantities, allocated wallets, or commitments about market prices.
* Token supply, vesting, fees, staking/slashing and the consensus code must be independently checked before any mainnet or public offer.
