# Contributing to research

This repository is a **public research proposal**, not a live blockchain or a token offering. Suggestions and corrections to protocol requirements, monetary modelling, security assumptions and documentation are welcome through GitHub Issues, if enabled by the maintainer.

When reporting an issue, provide the exact section, claim, expected correction and public supporting sources or reproducible calculation. Do not post personal data, secret keys, attack payloads or confidential credentials. Formal monetary policy changes require explicit versioned decisions; opening an Issue does not change the token economics.
